# GAIA Studio

Tạo ảnh, sửa ảnh và dựng video bằng AI trong một studio. Đăng nhập Google, nạp credit qua PayOS, thấy rõ giá trước khi tạo.

- **Bàn giao, trạng thái và việc còn dở**: xem [HANDOFF.md](HANDOFF.md)
- **Cài đặt từ đầu** (Supabase, Google, PayOS): xem [SETUP.md](SETUP.md)
- **Kiến trúc code**: xem [CLAUDE.md](CLAUDE.md)
- **Tài liệu API Gommo**: [docs/gommo-api.md](docs/gommo-api.md)

```bash
npm install
cp .env.example .env   # rồi điền khoá
npm run dev            # http://localhost:3000
```
