# Ghi chú làm việc của Claude

Bản sao ngày 12/10/2026 của bộ nhớ dự án mà Claude Code (trợ lý AI viết code cho GAIA) dùng giữa các phiên làm việc. Mỗi file là một ghi chú; `MEMORY.md` là mục lục.

Ghi chú được viết bằng tiếng Anh, ghi lại quyết định sản phẩm, quy ước giao diện, điều đã kiểm chứng về Gommo và trạng thái công việc theo từng ngày. Ngày ghi trong file là ngày của sự kiện đó; thông tin mới hơn nằm ở [HANDOFF.md](../../HANDOFF.md) và [CLAUDE.md](../../CLAUDE.md).

Không có khoá bí mật trong thư mục này.
