The user is the founder of GAIA, an early-stage Vietnamese startup. They make the product decisions themselves.

They like:
- Getting 2–3 concrete options with pros and cons and a marked recommendation, then choosing. AskUserQuestion worked well for this.
- Seeing a design before any code. They explicitly paused coding until all screens were designed.
- Facts that are sourced. When I stated something (e.g. 79ai's 90-day expiry), they asked "bạn đọc ở đâu thế?". Quote and link the source, and say clearly when something is inferred rather than verified.
- Cost-awareness. They chose cheaper options as a startup and plan upgrades later, and they approved paid API test runs only explicitly.

They sometimes share the mockup with a friend for feedback. The standalone HTML + PNG + zip in `mockup-gaia/` exists for that purpose.
