In GAIA Studio's UI, keep the industry terms content creators already know in English: start frame, end frame, text to video, image to video, reference, upscale, prompt, model, credit, ratio, resolution, mode. Use Vietnamese for actions, statuses and navigation (Tạo, Tải về, Xoá, Thử lại, Đang render, Hôm nay, Phiên bản) and for input placeholders.

**Why:** The user (2026-10-06) said creators always remember their field's English terms, and translated versions like "Khung đầu" or "Văn bản" sound worse.

**How to apply:** When writing or reviewing any user-facing string in the redesign, apply this split rather than translating everything. Related: [[user-language-vietnamese]].
